# B 站投稿文案（fxxk-off-dfy 宣传片）

## 想改片中文案

双击 `copy-editor.html`，左边按场景改字，右边是 1920x1080 的实时预览。
改完点「下载 copy.json」覆盖本目录的 `copy.json`，再跑：

```bash
python make_promo.py --encoder=h264_nvenc
```

20 秒出新片。字体统一用微软雅黑，中英文混排不会出现高低不齐。

## 标题（选一个，B 站上限 80 字）

1. 评论区被机器人刷屏，我写了个自动清理工具
2. 用 B站接口自动删机器人评论，写了个小工具
3. B站机器人评论，从服务端删掉

推荐第 1 个。

## 简介

```
B站评论区的 AI 机器人越来越多。油猴脚本只能让自己看不见，评论还挂在稿件下面，别人进来照样能翻到。

这个工具走 B站接口，定时扫自己视频的评论，判断是机器人就直接删掉，也可以顺带举报、拉黑。

开源地址：https://github.com/NothingCooker/fxxk-off-dfy

Windows 双击 4-gui.bat 就能用，纯 Python，没有第三方依赖。
默认是体检模式，只打印不删除，确认没有误判再开真删。

提示：删除不可撤销，建议先跑一天 dry-run 看日志。
```
