# B 站投稿文案（fxxk-off-dfy 宣传片）

## 标题（选一个，B 站上限 80 字）

1. 闹鱼灾了：我把评论区的机器人删了
2. 评论区不是机器人的殖民地
3. 用 B站接口删机器人评论，写了个小工具

推荐第 1 个，跟片子开场的「闹鱼灾了」对得上。

## 简介（三个版本，直接复制）

### 版本一：信息全（推荐）

```
评论区被机器人刷屏了。

这些号是真人号接了 AI，自动刷视频、自动发总结，昵称一水的「大肥鱼」，一条视频发出去十分钟就能刷到四五个。

油猴脚本只能让你自己看不见，评论还挂在稿件下面，别人进来照样能翻到。治标不治本。

这个工具走 B 站接口，定时扫自己视频的评论，认出机器人就直接删掉，也能顺带举报、拉黑。删的是真评论，所有访客都看不到了。

开源：github.com/NothingCooker/fxxk-off-dfy
Windows 双击 4-gui.bat 就能用，纯 Python，没有第三方依赖。

默认是体检模式，只打印不删除。建议先跑一天看日志，确认没有误判再开真删，删除不可撤销。

#B站 #开源 #Python #机器人
```

## 想改片中文案

双击 `copy-editor.html`，左边按场景改字，右边是 1920x1080 的实时预览。
改完点「下载 copy.json」覆盖本目录的 `copy.json`，再跑：

```bash
python make_promo.py --encoder=h264_nvenc
```

20 秒出新片。字体统一用微软雅黑，中英文混排不会出现高低不齐。
